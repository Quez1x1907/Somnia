# СОМНИЯ — сайт гильдии Free Fire, версия 2

Независимая копия `Quez1x1907/somnia-guild` с новым фото первого экрана и контактом офицера гильдии — [@ssh1ck](https://t.me/ssh1ck).

Исходный репозиторий и действующий сайт не изменяются. Чистые HTML, CSS и JavaScript, без сборки.

## Изменения

- Вместо цветов используется предоставленное фото `assets/hero-photo.webp`, оптимизированное для веба. Слева убрана узкая полоса со значками интерфейса.
- На компьютере фото и текст стоят рядом, на телефоне фото расположено над текстом: надпись на изображении не перекрывается заголовком.
- Контакт офицера добавлен в блок вступления и футер. Контакт лидера, канал, требования и эффекты сохранены.
- Дополнительные стили находятся в `updates.css`.

## Запуск

После завершения первого запуска **Actions → Prepare independent site copy** в корне появятся `index.html`, `styles.css`, `script.js` и все изображения.

```bash
python -m http.server 8123
```

Откройте http://localhost:8123. Для режима снимка страницы добавьте `?shot=1`.

## Публикация

Новый репозиторий сам по себе не публикует сайт. Настройте отдельный проект Cloudflare Pages: Framework preset — None, без команды сборки, каталог результата — корень проекта. Либо загрузите статические файлы вручную в отдельный проект.

Перед публикацией на новом адресе обновите `og:url` и абсолютный адрес `og:image` в `index.html`. Сейчас сохранены адреса оригинала; новая публичная ссылка ещё не назначена.

## Первоначальное копирование

Одноразовая автоматизация загружает файлы с действующего сайта и проверяет точное совпадение Git SHA каждого файла с исходным репозиторием на момент копирования. Затем применяет изменения и сохраняет полноценные статические файлы. После успешного копирования повторно запускать её не нужно: от перезаписи готового сайта предусмотрена защита.
